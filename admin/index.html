How do I get a token?
  1. Open GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: “Only select repositories” → choose your portfolio repo.
  3. Permissions → Repository → Contents: set to Read and write.
  4. Generate, copy the token, and paste it above. Only you have it — it is never stored on the website.
